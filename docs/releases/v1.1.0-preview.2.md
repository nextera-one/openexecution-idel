# IDEL 1.1.0 Preview 2

This preview removes the desktop IDEL / Edit / View menu bar. Use the direct **Workspace…** button to choose a folder and restart. The terminal's own tools menu remains available.

## Fixes

- Package Linux icons at standard theme sizes and set an explicit desktop window icon.
- Check existing audit trust, signatures and continuity before executing commands. Missing trust/checkpoint metadata now stops the first attempted command before it runs.
- Explain that default-policy LOW/MEDIUM typed commands run on Enter, while HIGH commands remain dry runs. Ask AI retains its separate approval flow.
- Keep the Ask AI setup button accessible when no provider is configured.

## Existing audit history

Audit history remains in `~/.idel`. If an older installation has records but lacks its verifier trust file or continuity checkpoint, the app will stop safely. Restore those files from a known backup, or explicitly preserve the old files in an archive before starting a new audit history. Never delete history or automatically trust a key to suppress the error. Starting a new history does not verify or extend the old chain. Restart IDEL after an audit recovery; do not blindly repeat an operation that reported a post-execution logging failure.

## Install and upgrade

Download the matching Windows x64 EXE, macOS Apple Silicon/Intel DMG, or Linux x64 DEB/AppImage. Compare its SHA-256 with `SHA256SUMS.txt`. Close IDEL and run the installer manually; there is no automatic updater. The app's base package version remains 1.1.0; the release tag and checksums identify preview 2.

On Debian/Ubuntu, prefer the DEB for installation of the desktop entry, icon theme files and sandbox integration. Extracting a DEB does not perform these installation steps. Reopen the app after updating so the running window uses the new icon.
